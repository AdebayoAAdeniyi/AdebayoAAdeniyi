# Dr. Adebayo A. Adeniyi

Computational chemist and data scientist. I build Python workflows for machine learning, cheminformatics and molecular modelling in drug discovery and natural product research.

## About me

- MSc in Computing Science, University of Alberta (June 2026). My thesis builds chemical language models (recurrent neural network and MolGPT style transformer) for de novo generation of natural products, trained separately on bacterial, fungal and plant metabolites.
- PhD in Chemistry, with about ten years as a university researcher and lecturer in computational chemistry.
- 71 peer reviewed articles on drug design, vaccine design, electrochemistry and photochemistry (h-index 18 on Google Scholar).
- Some of my earlier work compares experimental cyclic voltammetry with DFT modelling.

## What I work with

- Data and machine learning: Python, pandas, NumPy, scikit-learn, PyTorch, SQL, DuckDB, Matplotlib, seaborn
- Cheminformatics: RDKit, SMILES processing and property calculation
- Molecular modelling: docking, molecular dynamics, DFT, QM/MM
- Web basics: HTML, CSS and JavaScript
